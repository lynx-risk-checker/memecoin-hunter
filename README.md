# MEMECOIN HUNTER

Evidence-first Solana spot meme-coin research and paper-trading system.

## Safety state

The repository starts in **DRY_RUN + PAPER_TRADING** mode. Real-money execution is intentionally not implemented in the foundation.

## Architecture

Solana / DEX data -> Token Radar -> Early Flow -> 5-Min Forensics -> Dev DNA -> Smart Money -> Wallet Graph -> Manipulation Detection -> Liquidity / Exitability -> Narrative -> Asymmetric Edge -> Risk Veto -> Paper Execution -> Exit Monitoring -> Mission Journal.

## Capital mission

Initial mission: **Rp100,000 -> Rp1,500,000** over a defined mission window. This is an objective, not a profit guarantee. Strategy validation and capital-target status are tracked separately.

## Engineering rules

- Real data only for evidence; no fabricated market evidence.
- Never commit private keys or seed phrases.
- Risk veto can block a trade regardless of mission target.
- Paper trading precedes any live execution.
- No live order placement exists in this foundation.
- Do not merge to main without explicit Founder approval.
